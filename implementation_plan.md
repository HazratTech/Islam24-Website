# Plan: Industry-Grade Islamic App Website Redesign & SEO Elevation

Complete overhaul of the Islam24 website into a modern, industry-grade landing page inspired by top-tier apps (Pillars, Tarteel, WeMuslim). Features vibrant dark glassmorphism, interactive live app demos (Prayer times, Qibla compass, Zakat calculator, Tasbih counter, Quran reader), an Ad-Free comparison matrix, animated FAQ accordions, and rich search engine optimization.

## Design Highlights
- **Serene Dark Emerald & Metallic Gold Design System**: Backdrop-blur glassmorphism, glowing micro-borders, elegant typography (Outfit, Plus Jakarta Sans, Amiri Arabic script).
- **Interactive Live App Demos**:
  - Live Next Prayer Countdown with calculation method switcher.
  - Interactive rotating Qibla compass preview.
  - Interactive Zakat calculator widget (calculates 2.5% instantly on page).
  - On-page digital Tasbih counter clicker.
  - Offline Quran reader snippet with audio recitation toggle.
- **Ad-Free Comparison Matrix**: Clear visual table comparing Islam24 against ad-heavy apps.
- **SEO Dominance**: Schema.org JSON-LD structured data for SoftwareApplication, FAQPage, Organization, and high-volume search term targeting.
